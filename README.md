# MarketStats Terminal

Аналитический терминал объемов, микроструктуры и VSA для терминала QUIK (срочный рынок Московской биржи, FORTS).

## 🚀 Описание системы

Система состоит из двух взаимодействующих компонентов:
1. **Lua-скрипт для QUIK (`lua/Stats.lua`)**:
   - Непрерывно сканирует «Таблицу всех сделок» Московской Биржи.
   - Фиксирует тики, агрегирует 1-минутные бары (OHLC, объем, число сделок, оборот, Открытый Интерес, CLV, спред).
   - Сбрасывает данные в структурированные CSV-файлы.
2. **Настольный аналитический терминал C# .NET 9 WPF (`src/MarketStatsViewer`)**:
   - Автоматически синхронизирует и индексирует исторические сессии в локальную базу данных SQLite.
   - Считывает живой поток тиков и минутных баров каждые 2 секунды без блокировки файлов.
   - Сравнивает текущие показатели с историческими нормами (RVol, накопленный дневной объем, средний чек сделки).
   - Оценивает рыночный баланс по закону Вайкоффа «Усилие против Результата» (VSA).
   - Строит независимые вероятностные прогнозы по двум временным горизонтам: **5–15 минут** и **30–60 минут**.

---

## 📊 Ключевой функционал

- **Живой формирующийся бар (In-Progress Bar)**: обновление текущей цены, объемов и сделок каждые 2 секунды без ожидания закрытия минуты.
- **Детектор институциональной активности**: сопоставление дневного объема и среднего размера сделки с историческими нормами.
- **Анализ Открытого Интереса (ОИ)**: идентификация набора новых позиций против «шортокрыла» и сброса позиций.
- **VSA «Усилие / Результат»**: автоматическое распознавание скрытых лимитных поглощений (айсбергов), истинных пробоев и кульминаций объема.
- **Два горизонта прогноза**:
  - *5–15 минут*: тактический вход / скальпинг на основе микроструктуры.
  - *30–60 минут*: стратегический контекст и дневной баланс относительно VWAP.
- **Встроенная иллюстрированная справка**: окно с подробным описанием каждого блока интерфейса и торговыми сценариями.

## 🛠️ Сборка и запуск

### Требования:
- Windows 10/11
- .NET 9.0 SDK
- Терминал QUIK с доступом к срочному рынку (FORTS)

### Сборка из исходников:
```bash
cd src/MarketStatsViewer
dotnet build -c Release
dotnet publish -c Release -o ../../App
```

### Запуск:
Запустите `Start_MarketStats.bat` в корневой папке проекта.
